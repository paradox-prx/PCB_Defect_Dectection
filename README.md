# PCB Defect Detection

YOLO-based PCB defect detection experiments comparing a local PCB dataset run with a larger Kaggle PCB dataset run.

## Contents

- `experiments/`: training notebooks for run 1 and run 2.
- `data_pcb_github.yaml`: YOLO dataset config for the local PCB dataset.
- `RUN1_vs_RUN2_COMPARISON.md`: detailed comparison of both experiment runs.
- `results/`: lightweight top-level result summaries and plots.

Large datasets, W&B logs, and model checkpoints are intentionally excluded from git. Store those artifacts separately or use Git LFS if they need to be versioned.
